# EHMS-RHV

## Emergency Healthcare Management System for Remote Hilly Villages

**Team:** LifeLink

EHMS-RHV is an educational emergency healthcare coordination system designed for remote and hilly villages.

### Project Objective

The system focuses on coordinating emergency requests before and during the patient's journey to a healthcare centre.

### Technologies

- HTML, CSS, JavaScript
- Python Flask
- MySQL
- HTTP/REST
- Cisco Packet Tracer

### Core Concepts

#### DBMS
- Relational database
- Primary and foreign keys
- Transactions
- Resource management
- Emergency logging

#### Operating Systems
- Priority scheduling
- Emergency queue
- Resource allocation
- Synchronization
- Deadlock prevention

#### Computer Networks
- Client-server communication
- HTTP/REST
- Network topology simulation
- Network failure simulation
- Offline request synchronization
